READY TO INSTALL?

Fresh firmware.
Right from your browser.

Loading release information…

  1. Connect a compatible PourBot board with a USB data cable.
  2. Open this page in desktop Chrome or Edge and close any serial monitors.
  3. Select Connect & Install, choose the board and follow the installer.

For the JC3248W535C board only. A browser installation writes the bootloader and partition layout. This full USB image resets saved calibration, recipes and Wi-Fi settings. For an existing working scale, use Settings → OTA Update to keep your settings.

Use a desktop browser with Web Serial support, such as Chrome or Edge.

Open the HTTPS version of this page to install.

After installation, leave the platform empty for startup tare, then calibrate using a known weight. Configure Wi-Fi from Settings.
